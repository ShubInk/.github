# ShubInk

### A simpler way to discover and buy

ShubInk is building a connected commerce experience for discovering products, browsing a storefront, and completing the journey across web and mobile.

The problem we are solving is fragmented shopping: customers should have a clear storefront, a consistent experience across devices, and dependable services behind the scenes.
